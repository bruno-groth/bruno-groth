# Bruno Groth Portfolio

This is a Nuxt 3 portfolio website built with Vue.js, Tailwind CSS, and VueUse Motion.

## Features

- **Tech Stack:** Nuxt 3, Vue 3, Tailwind CSS
- **Animations:** VueUse Motion for smooth entrance animations
- **Icons:** Nuxt Icon (Iconify)
- **Design:** Dark mode, minimalist, developer-focused
- **Content:** Based on professional experience and skills

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Structure

- `components/`: UI components (Hero, Experience, Skills, Contact)
- `pages/`: Page views
- `layouts/`: Main layout
- `public/`: Static assets (Resume PDF)
